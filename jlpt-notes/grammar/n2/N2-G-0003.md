# 核心

## 功能一：因为是 A 这种情况，所以 B 理所当然

**くわしい意味記述：**

- **～以上（は）／～上は：** 話者の強い意志や義務感、決意を表す文型です。前件では既に発生した出来事を述べ、その状況下においてやるべき事柄を後件で述べます。（表示说话人的强烈意志、义务感或决心。前项叙述已经发生的事情，后项说明在该状况下理应去做的事。）

### 例句

1. 給料を貰ってる以上は一生懸命やるのみ。

   （既然领了工资，就只能努力干。）

2. 選ばれた以上、文句も言っていられない。

   （既然已经被选中，就不能再抱怨了。）

3. 試験勉強は一切してないが、会場に来た以上は全力を出そうと思う。

   （虽然完全没为考试复习，但既然来到考场，我就想全力以赴。）

4. 証拠が無い以上は無罪だと考えるべきだ。

   （既然没有证据，就应当推定为无罪。）

5. この仕事を引き受けた以上は責任をもってやり遂げる。

   （既然接下了这份工作，就要负起责任完成它。）

### 与～うえは对照

两者都表示“既然 A，就应当 B”。**～以上（は）重在以 A 为依据；～うえは重在表明 B 的觉悟。**这是侧重，不是互换规则。

| 比较点 | ～以上（は） | ～うえは |
|---|---|---|
| 一句话理解 | 既然事实是 A，B 就是应有的判断。 | 既然走到了 A，就要下决心做 B。 |
| A 常是什么 | 决定、事实、身份或状态。 | 已作出的决定、已发生的事。 |
| B 常是什么 | 义务、判断，也可以是决意。 | 责任、觉悟、决意。 |

| 句型 | 日语例句 | 着眼点 |
|---|---|---|
| ～以上 | **責任者に選ばれた以上、最後まで職務を全うしなければならない。**（对照改写） | **被选中了**，所以必须履职。 |
| ～うえは | **責任者に選ばれた上は、最後まで職務を全うする覚悟です。**（「はごろも」作例） | **被选中了**，我已做好履职到底的准备。 |
| ～以上 | **学生である以上、勉強はしっかりやらなければならない。**（「はごろも」作例） | 以“**是学生**”这一身份为依据；选「以上」更自然。 |

记忆时只问：**想强调“依据这个事实”，还是“表明接下来的觉悟”？**
