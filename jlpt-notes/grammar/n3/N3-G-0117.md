# 核心

## 功能一：引用・提示内容（口语中替代引用助词「と」「という」）

**最上位意味カテゴリー：**

- **って（引用）：** 人との関係（人际关系）

**中位意味カテゴリー：**

- **って（引用）：** 伝達（传达）

**意味：**

- **って（引用）：** 引用（引用）

**くわしい意味記述：**

- **って（引用）：** 日常の親しい話し言葉において，引用の格助詞「と」や「という」の代わりに用いる。板書説明：「提示内容『と』と同じ」。（在日常口语交流中，用于替代引用助词「と」或「という」。）

### 例句

1. 鈴木さんは30分ぐらい遅れるって言っていました。

   （铃木先生说他会迟到大约30分钟。）

2. あそこに「立入禁止」って書いてありますよ。

   （那上面写着“严禁入内”哦。）

3. この服はワークマンっていう店で買いました。

   （这件衣服是在一家叫“WORKMAN”的店里买的。）

4. 明日の集合時間は朝8時だって。

   （听说上级通知明天的集合时间是早上8点。）

## 功能二：伝聞（口语中表示听闻某事，替代「〜そうだ」）

**最上位意味カテゴリー：**

- **って（伝聞）：** 情報・知識（信息与知识）

**中位意味カテゴリー：**

- **って（伝聞）：** 情報源（信息来源）

**意味：**

- **って（伝聞）：** 伝聞（传闻）

**くわしい意味記述：**

- **って（伝聞）：** 第三者から聞いた話や噂などを相手に伝える際に，文末で「〜そうだ」「〜と聞いた」のくだけた口語表現として用いる。板書説明：「札幌行きの101便は雪の影響で欠航だって」。（在将从第三方听闻的信息或传闻转告对方时，在句末作为「〜そうだ」的口语轻便形式使用。）

### 例句

1. 札幌行きの101便は、大雪の影響で欠航だって。

   （听说明天飞往札幌的101航班因为大雪停飞了。）

2. 今年の夏は記録的な猛暑になるって、天気予報で言ってたよ。

   （天气预报说，今年夏天据传会成为破纪录的酷暑哦。）

3. 田中さんの奥さん、双子の赤ちゃんを出産したんだって。

   （听说田中先生的太太生了一对双胞胎宝宝呢。）

4. あの映画、すごく面白くて泣けるって評判だよ。

   （听说那部电影特别精彩感人，广受好评呢。）
