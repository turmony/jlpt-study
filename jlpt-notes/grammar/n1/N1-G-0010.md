# 核心

## 功能一：做 A 时顺便做 B；兼做 A 与 B

**くわしい意味記述：**

- **～かたがた：** 〜のついでに / 〜も兼ねて（做某事的同时顺便做另一件事；也兼做某事。）

### 例句

1. 今度、結婚の挨拶かたがた、そちらに伺います。

   （下次我会登门拜访，顺便向您报告结婚的事。）

2. 近くに寄ったので、先日のお礼かたがた挨拶に伺いました。

   （正好到了附近，我便来向您问候，也为前些日子的事道谢。）

3. ご出張かたがた、ぜひ京都を観光なさってください。

   （您出差时，也请顺道到京都观光。）

4. メールにて大変恐縮ではございますが、ご報告かたがたお礼申し上げます。

   （冒昧通过邮件向您汇报，同时也向您致谢。）
