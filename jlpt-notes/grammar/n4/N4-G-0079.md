- **核心句型与接续要点**：
  - 语法形式优先用平假名，并在括号中标注对应汉字。
  - **句型 1：お ＋ 動詞ます形 ＋ になります**
    - 和语动词（和語動詞）：`お` ＋ ます形（去掉ます） ＋ `になります`
    - 例：`かえ(帰)ります` → `おかえ(帰り)りになります`、`よ(読)みます` → `およ(読)みになります`
  - **句型 2：ご ＋ 動作性名詞 ＋ になります**
    - 汉语动作名词（漢語名詞）：`ご` ＋ 动作名词 ＋ `になります`
    - 例：`しゅっせき(出席)します` → `ごしゅっせき(出席)になります`、`りよう(利用)します` → `ごりよう(利用)になります`
  - **句型 3：お ＋ 動詞ます形 ＋ です / ご ＋ 動作性名詞 ＋ です**
    - 表示尊长当下的状态或情况（相当于 `～ています` 的尊敬语）
    - 例：`ま(待)ちます` → `おま(待)ちです`（正在等候）、`も(持)ちます` → `おも(持)ちです`（正持有/随身携带）

## 语法解说与补充

### 核心语义与使用禁忌（板书核心精髓）

1. **一音节动词绝对排除原则（一音節の動詞は×）**：
   - 如果动词去掉 `ます` 后**只有一个音节（假名）**，绝对**不能**套用 `お～になります`！
   - 例如：
     - `き(来)ます`（只有き一个音节）不能说 `*お来になります`，必须用特殊尊敬语 `いらっしゃいます`！
     - `み(見)ます`（只有み一个音节）不能说 `*お見になります`，必须用特殊尊敬语 `ご覧になります`！
     - `ね(寝)ます`（只有ね一个音节）不能说 `*お寝になります`，应用 `お休みになります`！
     - `し(為)ます` 不能说 `*おしになります`，必须用 `なさいます`！
2. **已有特殊尊敬动词的动词不套用此句型**：
   - 既然已有 `召し上がる`、`いらっしゃる`、`おっしゃる` 等固有词，日常优先使用特殊动词。

### 易混淆对比：お～になります（尊敬） vs お～します（谦让）

这是日语敬语学习中最致命的陷阱，也是 JLPT 的“常青树”考题：

| 句型 | 敬语类别 | 动作发出者 | 常见主语 | 典型示例 |
| :--- | :--- | :--- | :--- | :--- |
| **お～になります** | **尊敬語** | 对方 / 尊长 / 客户 | 先生、社長、お客様 | `社長はお帰りになりました。`<br>（社长已经回家了） |
| **お～します** | **謙譲語** | **说话人自己 / 我方** | 私、社員 | `私が荷物をお持ちします。`<br>（我来替您拿行李） |

### JLPT 考点聚焦

1. **`お～です` 表示状态**：经常在接客对话中考查，如前台问顾客：`「メンバーズカードはお持ちですか。」`（您有会员卡吗？）。
2. **前后呼应与助词搭配**：考查 `お...になります` 与 `お...します` 的选择，关键是**抓句子主语**。主语是社长/客人选 `お～になります`，主语是自己选 `お～します`。
