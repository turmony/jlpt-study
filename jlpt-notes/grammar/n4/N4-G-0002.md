# 核心

## 功能一：打算做 A

**最上位意味カテゴリー：**

- **つもりだ：** 考え・感情（想法与感情）

**中位意味カテゴリー：**

- **つもりだ：** 意志（意志）

**意味：**

- **つもりだ：** 意志・予定（意志与预定）

**くわしい意味記述：**

- **つもりだ：** 「〜ようと思っている」「〜する予定だ」という意味を表す。将来行う，あるいは行わない，話し手の意志や予定を表す。（表示“打算……”“预定做……”之意。表示说话人预先持有的、在将来要做或不做的意志与预定。）

**派生語：** 未列出

### 例句

1. 私は将来医者になるつもりです。

   （我打算将来成为一名医生。）

2. 引越しをするつもりで、荷物を片付け始めています。

   （我打算搬家，已经开始收拾行李了。）

3. どんなにつらいことがあっても、私は耐えて行くつもりです。

   （无论发生多么痛苦的事，我都打算坚持忍耐下去。）

4. え、これから一体どうするつもりなんだい、お前。

   （哎，你今后到底打算怎么办啊。）
