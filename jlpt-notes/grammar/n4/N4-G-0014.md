# 核心

## 功能一：做 A（命令表现）

**最上位意味カテゴリー：**

- **Vなさい：** 働きかけ（施加影响）

**中位意味カテゴリー：**

- **Vなさい：** 命令・依頼（命令与请求）

**意味：**

- **Vなさい：** 命令（命令）

**くわしい意味記述：**

- **Vなさい：** Vで表す行為を相手に命令する意味。「V命令形」よりもやわらかく言いたいときに使う。（表示命令对方进行动词所示行为之意。用于想比动词命令形语气更委婉地表达命令时。）

**派生語：** 未列出

### 例句

1. 早く起きなさい。

   （快点起床。）

2. ここに名前を書きなさい。

   （在这里写上名字。）

3. ご飯を食べる前に、ちゃんと手を洗いなさい。

   （吃饭前要好好洗手。）

4. 質問があったら、手を挙げなさい。

   （如果有疑问，请举手。）
