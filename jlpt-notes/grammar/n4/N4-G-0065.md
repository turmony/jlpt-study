# 核心

## 功能一：保持 A 的状态而做 B

**最上位意味カテゴリー：**

- **まま（場所・時間）：** 場所・時間（场所与时间）
- **まま（ものごとの様子）：** ものごとの様子（事物的样态）

**中位意味カテゴリー：**

- **まま（場所・時間）：** 時間的前後（时间先后）
- **まま（ものごとの様子）：** 変化・不変化（变化与不变化）

**意味：**

- **まま（場所・時間）：** 範囲（范围）
- **まま（ものごとの様子）：** 経過（经过）

**くわしい意味記述：**

- **まま（場所・時間）：** ある状態が変わらずに続いていることを表す。（表示某种状态保持不变地持续着。）
- **まま（ものごとの様子）：** ある状態が変わらずに続いていることを表す。（表示某种状态保持不变地持续着。）

**派生語：** 未列出

### 例句

1. 弟はめがねを掛けたままで寝ています。

   （弟弟戴着眼镜睡着。）

2. トマトは生のまま食べる方がおいしい。

   （番茄生着吃更好吃。）

3. そんな私がつい先日、携帯電話を充電したまま家に忘れてきてしまいました。

   （就在前几天，这样的我竟把手机连着充电器就那样忘在了家里。）

4. 駅のベンチで寝ようってことになってさ、私、洋服のまま寝るのはいやだって

   （说好要在车站的长椅上睡，我说我可不想就这样穿着衣服睡。）

## 功能二：A 的状态、状况保持不变地持续着

**最上位意味カテゴリー：**

- **まま（場所・時間）：** 場所・時間（场所与时间）
- **まま（ものごとの様子）：** ものごとの様子（事物的样态）

**中位意味カテゴリー：**

- **まま（場所・時間）：** 時間的前後（时间先后）
- **まま（ものごとの様子）：** 変化・不変化（变化与不变化）

**意味：**

- **まま（場所・時間）：** 範囲（范围）
- **まま（ものごとの様子）：** 経過（经过）

**くわしい意味記述：**

- **まま（場所・時間）：** ある状態が変わらずに続いていることを表す。（表示某种状态保持不变地持续着。）
- **まま（ものごとの様子）：** ある状態が変わらずに続いていることを表す。（表示某种状态保持不变地持续着。）

**派生語：** 未列出

### 例句

1. 弟は、すぐ帰ってくると言って出掛けたままで、連絡もしてこない。

   （弟弟说马上就回来，出了门之后就一直没有联系。）

2. いくつかの重要な問題が未解決のまま残っている。

   （有几个重要的问题仍未解决地留在那里。）

3. この地域に対する民間投資は低いままだった。

   （对这一地区的民间投资一直很低。）

4. カリフォルニア州では停電が続発、ガソリン価格も高騰したままだ。

   （加利福尼亚州停电接连发生，汽油价格也一直居高不下。）
