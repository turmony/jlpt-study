# iPad 阅读器界面

## 审查与方向

原界面采用暖纸色与青绿配色，标题偏粗，组件圆角不一致；CSS 多轮覆盖使样式难以维护。目录的 grid 布局还会被 Material 的列表样式覆盖，目录链接被即时导航转换为完整网址后，正文搜索无法正确匹配。

使用 `.agents/skills/ui-ux-pro-max` 审查触控、文字对比度、响应式布局与焦点遮挡。设计系统查询的营销页面结构不适用于阅读器；采用其简洁排版建议，具体视觉遵循 Google 官方页面与学习场景。

参考 [Google 官方 Gemini 页面](https://blog.google/products-and-platforms/products/gemini/) 的 Google Sans 字体、白色背景、蓝色操作与圆角按钮。整体采用浅灰画布、白色阅读区、轻量标题、少量蓝紫渐变；深色模式为炭灰画布与浅蓝操作。没有复用 Google 商标。

## 实施

- 字体：本地 Google Sans + Noto Sans JP + 简体中文补字。详情与授权见 [字体说明](../reader/assets/fonts/README.md)。
- 阅读：正文默认 18 CSS px，行高 1.9–1.95；正文上限 920 CSS px，章节分隔、引用和表格共享语义色。
- 来源：完整来源元数据保留在「来源资料」展开项中，避免技术字段占满阅读页首屏。
- 控件：胶囊搜索框与设置，统一圆角卡片；点击区域至少 44 CSS px，作答选项和提交按钮至少 48 CSS px。
- 布局：按实际宽度重排，支持横竖屏、iPad 分屏；长标题换行，表格在需要时局部滚动。
- 作答：保留选择、排序、不确定、草稿与提交规则；增加选中状态的读屏属性和作答进度播报。当前题边框不覆盖已答状态。
- 搜索：识别即时导航生成的同源绝对链接，继续拒绝外站链接进入本地正文索引。
- 校验：本地字体及许可证必须随临时站点发布；不增加外部字体、脚本或搜索请求。

学习资料、卡片提交审核与七天复习规则未改动。界面修改后关闭并重新启动阅读器以重新生成页面，再刷新 iPad Safari。

- 32 项 JavaScript 回归通过；插件集成测试 28 项通过，包括本地字体与许可证的实际发布。
- 18 个浏览器页面场景通过，覆盖 834/1194/1366/512/375 CSS px、明暗主题、字号放大、减少动态效果、搜索、作答与草稿恢复。使用本机 Chromium 模拟尺寸，未代替 iPad Safari 实机验收。

- 实际构建另有既有题源 `.txt` / `manifest.json` 链接不发布的提示，未更改学习资料以消除提示。

## 深色答题调整（2026-10-02）

- 保留 Google Sans、Noto Sans 和纯色炭灰背景。选项改用独立深灰填充，设置、搜索与题号减少常态亮色外框；选中使用蓝灰底色、勾选图标，键盘焦点保留浅蓝轮廓。
- 选项编号移入按钮；排序题同时显示选项编号和当前点击顺序，撤销与恢复草稿会同步更新序号及读屏标签。选中状态的数字在明暗两种主题中的对比度分别为 6.04:1 和 6.51:1。
- 仅未提交的 paper 答题页隐藏文章目录，顶部题号与底部提交栏保留；普通卡片和已提交试卷仍显示目录。答题阅读区上限为 920 CSS px，提交栏跟随实际阅读区对齐。
- 完整 Python 回归 293 项及 40 个子测试通过，JavaScript 回归 32 项通过。最后的浏览器检查覆盖明暗主题各 375/512/834/1194/1366 CSS px，以及选择、撤销、排序、不确定标记、草稿恢复、提交载荷、键盘焦点、放大字号、减少动态效果和即时导航，未发现页面脚本错误。
- 实际资料库构建生成 1,889 个页面，构建前后 1,888 份 Markdown/JSONL 的内容哈希、大小和修改时间一致；浏览器中的提交检查使用临时试卷，未提交真实学习答案。
- 本机 Chromium 尺寸模拟尚未代替 iPad Safari 实机确认。Ruff 的四项既有诊断与修改前一致，没有新增诊断。
